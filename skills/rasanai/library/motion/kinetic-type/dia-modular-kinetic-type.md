## What it is

DIA is a design studio founded in New York in 2009 by Mitch Paone and Meg Donohoe, now working from the French Alps, that builds kinetic identities and typographic systems. Their position, in the pages fetched here, is that motion is not applied to a finished identity; it defines the identity from the start. Creative Review quotes Paone on converting "our traditional understanding of typography" into digital and motion contexts. It's Nice That reports that DIA challenges animated type that is "on" and "off", building systems where type transitions continuously, generating dozens or hundreds of variations before choosing, with Paone's jazz-piano background informing a view of typography as music theory: master the rules, then break them. Paone's essay "Time Is the Material" frames kinetic identity as design where time is the primary material and places it in a line from 1970s PBS identities, MTV's modular logos, 8vo and The Designers Republic, to network branding.

Named works in the sources: the A-Trak identity (2016) as the breakthrough, the Squarespace rebrand (2018, "typographic rigor with procedural logic"), and the Nuits Sonores tool (letters and shapes behaving "like fragments of music, vibrating, scattering and recombining", per a search result; not confirmed by a fetched page).

## The defining traits (numbers)

- System over effect: a grid, a module set, a small vocabulary of behaviours, one rule for assigning them. The pages fetched give no numeric specs; the numbers below are derived working values.
- Grid: 12 x 6 cells of 160 px at 1920x1080 (derived), glyphs snap to cell boundaries.
- Behaviour vocabulary (derived from the described practice): slide by one or more cells; scale-stretch to 2x or 3x on one axis; rotate 90 degrees; weight swap (300 to 900); width swap; mask reveal by a cell; repeat/tile; drop-out (cell goes empty for a beat).
- Timing: letter transitions 250 to 600 ms; module cycles 800 to 1600 ms; the loop 4 to 8 s, aligned to bars.
- Rhythm: assign behaviours with a pattern (on-beat, off-beat, triplet) so the system feels played rather than randomised; this follows the jazz-piano framing in It's Nice That.
- Type: variable or multi-weight grotesques; high-contrast weight changes carry emphasis. Free options with variable axes: Inter (wght), Roboto Flex (wght, wdth, many axes), Anybody (wdth, wght), Bricolage Grotesque, Familjen Grotesk. All OFL on Google Fonts.
- Colour: usually restrained, one or two flat colours; the motion carries the identity (derived from the sources' emphasis on behaviour, not stated).
- Delivery: the same system exports to social, motion toolkits and tools that teams run themselves (generative tool alongside guidelines, per the search description).

## How to build it

### 2D (HyperFrames, GSAP, 1920x1080, 30 fps)

```js
function mulberry32(a){return function(){a|=0;a=a+0x6D2B79F5|0;let t=Math.imul(a^a>>>15,1|a);t=t+Math.imul(t^t>>>7,61|t)^t;return((t^t>>>14)>>>0)/4294967296}}
const CELL = 160, BEAT = 0.5;                                 // 120 bpm = 0.5 s; bar = 2 s
const rnd = mulberry32(2018), tl = gsap.timeline({ paused: true });
window.__timelines["03-dia-type"] = tl;
const glyphs = gsap.utils.toArray(".g");                      // one span per letter, absolutely positioned on cell grid
const B = {                                                   // the behaviour vocabulary
  slide:  (g,t) => tl.to(g, { x: "+=" + CELL*(rnd()<.5?-1:1), duration:.4, ease:"expo.out" }, t),
  weight: (g,t) => tl.to(g, { fontVariationSettings: "'wght' " + (rnd()<.5?900:300), duration:.5, ease:"power3.inOut" }, t),
  stretch:(g,t) => tl.to(g, { scaleX: 2, transformOrigin:"0 50%", duration:.35, ease:"power3.inOut" }, t)
                     .to(g, { scaleX: 1, duration:.35, ease:"power3.inOut" }, t + BEAT),
  turn:   (g,t) => tl.to(g, { rotation: "+=90", duration:.45, ease:"power3.inOut" }, t),
  mask:   (g,t) => tl.fromTo(g, { clipPath:"inset(0 100% 0 0)" }, { clipPath:"inset(0 0% 0 0)", duration:.4, ease:"expo.out" }, t),
};
const names = Object.keys(B);
for (let bar = 0; bar < 4; bar++) {
  glyphs.forEach((g, i) => {
    const onBeat = (i + bar) % 3;                             // rule: glyph i plays on beat (i+bar) mod 3 of the bar
    B[names[Math.floor(rnd()*names.length)]](g, bar*4*BEAT + onBeat*BEAT);
  });
}
// last 600 ms of the loop: reset every glyph to its rest state so the message reads
tl.to(glyphs, { x:0, rotation:0, scaleX:1, fontVariationSettings:"'wght' 600", duration:.6, ease:"power3.inOut", stagger:0.02 }, 7.2);
```

Rules:
1. No `opacity` tweens on glyphs. A glyph that disappears does so by moving out of a mask or by a cell going empty.
2. Every behaviour start time is on the beat grid: `start = k * BEAT`.
3. Choose behaviours from the seeded generator once, in order, at build; never inside a callback.
4. Load the variable font with `@font-face` and `font-weight: 100 900`; confirm the axis exists (e.g., Inter wght 100 to 900) or `font-variation-settings` will not move it.
5. Keep a rest state in each bar so the line can be read.

### 3D (Rasan3D)

Per-glyph extrusion with a fixed grid in world units. `k.extrudeText` needs TTF/OTF, not WOFF2.

```js
camera: { pos:[[0,[0,0,16]]], target:[[0,[0,0,0]]], lens:[[0,135]] },   // flat, graphic, T0 locked or a 3% push
async build(k){
  const r = k.rng(2018);
  const glyphs = "SYSTEM".split("").map((ch,i) => {
    const m = k.extrudeText(ch, { font:"assets/fonts/Inter-Black.ttf", size:1.2, depth:0.06, bevel:0.004, material:k.material("ceramic",{color:"#f2efe8"}) });
    m.position.set((i-2.5)*1.4, 0, 0); return m;
  });
  const plan = glyphs.map(() => Array.from({length:8}, () => Math.floor(r()*4)));   // behaviour per beat, fixed at build
  return { glyphs, plan };
},
pose(t, k){
  const beat = Math.floor(t / 0.5), p = (t / 0.5) - beat;
  k.objects.glyphs.forEach((g,i) => {
    const e = k.ease("power3.inOut")(Math.min(1, p / 0.8));
    const b = k.objects.plan[i][beat % 8];
    g.rotation.y = b===1 ? Math.PI/2 * e : 0;
    g.scale.x = b===2 ? 1 + e : 1;
  });
}
```
`pose` stays pure of `t`: the plan is built once from `k.rng`. Light with `top-soft`, no DoF, motion blur on.

## What makes a cheap imitation

- A word that staggers up letter by letter. That is an entrance, not a system.
- Random jitter and wobble with no grid: the identity reads as a screensaver.
- Too many behaviours (more than about 8) or only one.
- Using a fixed-weight font so weight changes are cross-fades.
- Never reaching a rest frame: the brand name cannot be read.
- Motion that is not locked to the audio's pulse: the point of the musical analogy is rhythm.
