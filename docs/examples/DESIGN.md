# Tally design system

## Overview

Tally feels like a tidy desk: paper-white ground, confident near-black type, and one mint signal reserved for the moment the numbers balance.

## Do's and Don'ts

- Do keep mint for the single balanced or confirmed state on screen.
- Do set numbers in JetBrains Mono with tabular figures.
- Don't use gradients or glassy surfaces.
- Don't put more than one accent element in a frame.
